# Daily Companion v2
Morning check-in requires 3 photos, morning weight and pee confirmation before the detox-tea reminder unlocks. Water target is 4 L (8 x 500 ml). The tea reminder says 2 teaspoons and 2–5 minutes steep/draw time.

This prototype does not yet send true scheduled push notifications; the reminder is available in-app after the check-in is complete.
